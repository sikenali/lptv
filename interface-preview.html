LPTV · 央视频 Linux 移植版

顶部功能区 #lx-topbar

  • 整条可拖拽移动窗口（easy_drag=True）
  • 最右侧最小化 / 置顶 / 小浮窗 / 全屏 / 最大化 / 关闭
  • 按钮区 .tb-btn 是 no-drag 区，不会误拖
  • 闲置自动上移隐藏，鼠标进入窗口重新出现

底部控制栏 #lx-controls

  • 上一台 / 播放暂停 / 下一台（↑ ↓ 空格）
  • 音量条 + 静音（M）
  • 录制（R）、截图（X）
  • 节目单（E）、频道（S）、设置

频道面板 #lx-panel

  • 59 个频道：央视 21 / CGTN 6 / 卫视 32
  • 分类标签切换 + 收藏过滤
  • 数字键 1-9 直选频道
  • 收藏持久化到 ~/.local/share/lptv/lx.state.json

节目单 #lx-epg

  • 央视频 capi EPG 接口取节目表
  • 支持节目预约与预约列表
  • 「CCTV-14 少儿」等无 cnlid 的频道按 pid 兜底

浮窗与录制状态

  • #lx-floatctl：小窗模式只保留上一台/播放/下一台/退出
  • #lx-rec-badge：录制角标常显，UI 闲置也能看到
  • 录制 = MediaRecorder webm 分块 → 桥 base64 落盘
  • 截图 = canvas 取画面 → 桥 base64 落 PNG

录制实现要点

  • 画面用 canvas 重绘（避开官方播放器保护）
  • 分块约 96KB，规避 WebView2 postMessage 体积限制
  • 切台自动停止录制，防混流
  • 落盘前 validate=True 严格解码，损坏分块直接报错
预览页仅还原界面结构与布局，不含真实播放能力——央视频画面需 Widevine CDM 解码， 且 LPTV 本体运行在 pywebview 的 QtWebEngine 里（Linux）/ WebView2（Windows），二者同套 pywebview 桥机制。
完整功能：切台 · 收藏 · 节目单预约 · 录制 · 截图 · 置顶浮窗 · 自动全屏 · 开机自启 · 画面模式（contain/cover/fill）· 快捷键全消费 · Ctrl+D 隐藏覆盖层 · 远程 catlink 转发。
