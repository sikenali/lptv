# LPTV 设置面板视觉优化 — 设计

日期：2026-11-24
状态：待批准
前置：首页设置弹窗已上线（右侧滑出侧边栏，3 标签：播放设置/快捷键/关于）。

## 意图

用户反馈设置面板需要优化三处：字号偏小、两个播放设置项的样式不够好看、右上角 ✕ 关闭按钮多余。改为：整体放大字号、两个设置项改成 iOS 风格开关卡片行、去掉 ✕（关闭依赖点击侧边栏之外或 Esc）。

## 目标

1. **字号放大 ~2px**：正文 15→17px，小节标题 17→19px，标签 14→16px，kbd 12→13px，关于区各文字同步放大（ver 14→16 / desc 16→18 / slogan 15→17 / foot 13→14）。
2. **播放设置两个项改为 iOS 风格开关卡片行**：整行做成圆角玻璃卡片（浅色描边 + 内边距 + 悬停），右侧为开/关拨动开关（toggle），勾选状态用强调色（`--accent`/`--accent2`）。保留 `<input type="checkbox">` 状态与 `change` 持久化逻辑不变（只改样式与结构）。
3. **去掉右上角 ✕ 关闭按钮**：删除 `.lv-set-close` 元素与其 CSS/JS；关闭仅保留「点击侧边栏之外（遮罩区）+ Esc」两种方式。
4. 深色/浅色两套主题都覆盖新样式。

## 方案（已定：iOS 开关 + 放大字号）

- **开关**：`input[type=checkbox]` 设 `appearance:none`，做成 52×30 胶囊轨道，`::after` 白色圆钮（24px），`:checked` 时轨道变 `--accent`、圆钮 `translateX(22px)`。
- **卡片行**：`.lv-set-row` 改为 `display:flex;justify-content:space-between;padding:16px 18px;border-radius:16px;background:rgba(255,255,255,.06);border:1px solid rgba(255,255,255,.1)`，hover 提亮；两行间距 12px；去掉原 `border-bottom` 分隔线。
- **浅色主题**：行背景 `rgba(0,0,0,.04)`、描边 `rgba(0,0,0,.1)`；轨道未选 `rgba(0,0,0,.14)`，选中 `--accent`；文字 `#1a2233`。
- **去掉 ✕**：删标记（`<button class="lv-set-close">`）、`.lv-set-close` CSS（深/浅两套）、`.lv-set-close` click 分支；`.lv-set-card-wrap` 顶部内边距保留 40px。

## 非目标 / 反目标

- 不改设置面板结构（3 标签、各面板内容、快捷键/关于面板）。
- 不改关闭逻辑的语义（遮罩/Esc 关闭已生效，仅去掉 ✕ 入口）。
- 不动首页齿轮按钮、播放界面、频道/节目单面板、深色主题基座。

## 实现文件

- `android/www/inject.js`（CSS 块 + 播放设置标记 + 关闭按钮删除）。

## 验证

2. 关闭：点 ✕ 已无；点侧边栏之外（遮罩）关闭；Esc 关闭；勾选框聚焦时 Esc 仍关闭（已有接管分支）。
