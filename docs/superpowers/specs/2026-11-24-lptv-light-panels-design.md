# LPTV 浅色主题下频道/节目单面板液态玻璃化 — 设计

日期：2026-11-24
状态：待批准

## 意图

浅色主题（`data-theme=light`）下，左侧频道面板与右侧节目单面板目前仍是**深色玻璃**（`--panel` = `rgba(10,15,28,.85)`），浮在浅色场景上不一致，内部条目/文字仍按深色样式。改为与首页卡片、设置弹窗一致的**浅色液态玻璃**（浅色半透明 + 深色文字 + 细边框）。

## 目标

1. 浅色主题下 `.lv-left-panel` / `.lv-right-panel` 背景改为浅色半透明液态玻璃（如 `rgba(255,255,255,.72)`），保留 `backdrop-filter:blur(30px) saturate(160%)`，边框 `rgba(0,0,0,.1)`，投影改浅色。
2. 面板内部全部元素（标题/关闭/标签/列表项/时间/进度/徽标/预约按钮/脚注）补 `[data-theme=light]` 覆盖：浅色表面 + 深色文字（`#1a2233` 主 / `#5a6b8c` 次 / `#8a94ab` 弱）+ 强调色 `#4d7cfe`。
3. 深色主题不受影响（所有改动在 `[data-theme=light]` 块内）。
4. 场景区（面板背后）提示胶囊 `.lv-hint-capsule` / `.lv-glass-capsule` 已有浅色覆盖，仅核验不重做。

## 非目标 / 反目标

- 不改 JS 逻辑、不改面板结构、不改深色主题样式。
- 不改首页卡片、播放界面、设置弹窗（其浅色已就位）。
- 不做动画/交互改动（面板滑入滑出动效不动）。

## 方案（已定：浅色液态玻璃）

在 `android/www/inject.js` 的 `[data-theme=light]` 块内（现 `:1327-1336` 附近）为左/右面板内部元素补一组覆盖。取值镜像首页卡片浅色：
- 表面：条目 `rgba(255,255,255,.85)`，hover `#fff`，当前项 `#fff` + 强调边框；标签 `rgba(0,0,0,.06)`，`.on` 白卡 + 深字。
- 文字：主 `#1a2233`，次 `#5a6b8c`，弱 `#8a94ab`，强调 `#4d7cfe`/`#6aa8ff`。
- 边框/分隔：`rgba(0,0,0,.12)` / `rgba(0,0,0,.08)`。
- 台标底 `.lv-left-logo`/`.lv-scene-logo`：`#f2f4f8`。
- 徽标 `.lv-right-badge`：`rgba(77,124,254,.14)` 底 + `rgba(77,124,254,.5)` 边 + 深字。

## 实现文件

- `android/www/inject.js`（仅 `[data-theme=light]` CSS 块）。
- 设计文档：`docs/superpowers/specs/2026-11-24-lptv-light-panels-design.md`。

## 验证

1. 浅色主题打开频道面板：面板为浅色玻璃，标题/关闭/标签/列表项/台标/名称/副标题/脚注均可读、对比正常。
2. 浅色主题打开节目单面板：面板为浅色玻璃，日期标签/节目条目/时间/进度/直播中/预约按钮/脚注均可读。
3. 深色主题下两面板与改动前完全一致（回归）。
4. `node --check android/www/inject.js` 通过；`bash run.sh` 手动确认。
