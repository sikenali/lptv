# LPTV 深浅主题液态玻璃 + 标签/主题切换动效 — 设计

日期：2026-11-26
状态：待批准
范围：`web/inject.js`（单文件注入 UI，CSS + JS）

## 意图

现有深浅主题是两套独立写死的颜色：浅色靠 158 条 `[data-theme=light]` 覆盖去补 208 处深色硬编码，漏一处就出现"浅底白字"；暗色玻璃是扁平的半透明白块，缺液态玻璃的高光/折射层次；三类标签（频道分组、节目单 5 天、设置 3 项）点击都是 `innerHTML` 全量重建，硬切且丢滚动位置；主题切换是瞬时翻转并重建首页，生硬闪变；遥控器左右键目前只调音量，无法切标签。

本次要做的是：把两套材质收敛成一套可切换的液态玻璃令牌、给三类标签统一柔和切换动效并接入遥控导航、给主题切换做"右上 → 左下"的卷轴式擦除过渡，同时保证深/浅两种主题下文字可读、软件合成端不卡。

## 目标

1. 深浅主题共用一套材质令牌与几何；切换只换令牌值，不再各写一套样式。
2. 深色达到与浅色同级的液态玻璃质感（渐变底、顶边高光、折射描边、弥散投影、hover 斜向光带）。
3. 三类标签统一：选中胶囊指示条平滑移动 + 内容淡出/淡入 + 保留滚动位置；支持遥控左右切换、上下在列表内移动焦点、OK 确认。
4. 首页↔播放/面板/切台的视图切换做柔和转场（淡出 + 轻微缩放，240ms 内），与标签动效区分。
5. 主题切换为对角卷轴擦除：右上起、左下收，边带带卷曲阴影；切换过程不闪白、不重建首页。
6. 全部文字在两种主题下满足对比度目标；`.perf`（软件合成）与 `prefers-reduced-motion` 下有降级路径。

## 非目标 / 反目标

- 不改页面结构、不改播放器/切台/EPG 抓取逻辑、不加新的设置项。
- 不做系统主题跟随、不做主题自定义色。
- 不把全屏 `clip-path` 或 `backdrop-filter` 动画放进主路径（xpra 软件合成会掉帧）。
- 反目标：切主题闪白/黑屏、过渡中断留残影、标签快切错位、遥控误触音量、浅色下出现白字、滚动位置丢失。

## 约束

- 画布是 1920×1080 经 `transform:scale()` 缩放，所有动效按设计像素写，跟随缩放。
- 运行环境含 CDE/xpra 软件合成（`__LPTV_IS_CONTAINER` / `__LPTV_SOFTWARE_GPU` → `.perf`，关闭全部 blur）与 Electron/Android 硬件合成。
- 现有按键语义必须保留：播放态 ↑↓ 换台、←→ 音量、空格播放暂停、C/E 开面板、Backspace 返回。
- 主题持久化走 `cfg.theme`（`saveCfg`），启动时在 `boot()` 恢复。

## 性能原则（CDE / 智慧屏优先）

AppImage / exe（Electron 硬件合成）是次要目标；**CDE 与智慧屏（xpra 软件合成）是主验收环境**，所有动效先按最差环境设计，硬件端只做增强。

硬性规则：

1. **只动 `transform` 与 `opacity`**。禁止动画 `width/height/left/top/margin/filter/box-shadow/background-position`；阴影/光带的变化用预置层的透明度表达，不逐帧重绘阴影。
2. **禁止全屏模糊动画**。`backdrop-filter` 只在静态态存在；任何过渡期间给 root 加 `lptv-theme-anim` / `lptv-tab-anim` 类临时关闭 blur（软件合成下 blur 重栅格化是最大开销，令牌切换本身也会触发全部模糊层重绘）。
3. **动画层数上限 2**（一个内容层 + 一个边带/指示条）。`will-change` 只在动画期间挂，结束立即移除，避免 xpra 下的图层内存与合成开销。
4. **不做逐帧 JS 测量**。位置在动画开始时一次性测量（offset 系），动画全程由 CSS transform 驱动；快速连点用 token 丢弃，不叠加动画。
5. **CDE 预算**：主题过渡 ≤ 700ms、标签切换 ≤ 400ms；过渡期间单帧 ≤ 50ms、平均 ≥ 24fps；不允许出现全屏 damage 的连续模糊重绘。
6. **自降级**：过渡期间用 rAF 采样帧间隔，若连续 3 帧 > 50ms，置 `cfg.motionLite = true` 并持久化，此后所有动效走 lite 档（无光带、无卷曲层、时长减半、纯淡化）。用户可在设置里恢复（可选，不新增界面则仅自动）。
7. **静态态也要省**：`.perf` 下光带为静态高光（hover 不做位移），logo/文字投影保留但不参与动画；列表重建只更新变动节点，不整段 `innerHTML` 重刷（EPG 切天复用已缓存日期）。
8. **主题切换不得重建首页**。`renderHome()` 的重建既打断过渡，又触发整页重新布局与模糊层重栅格化。

性能档位：

| 档位 | 判定 | 主题过渡 | 标签切换 |
|---|---|---|---|
| `full` | 硬件合成、非 `.perf` | 真实对角卷轴层（≤2600×2600 旋转层 + 卷曲边带），900ms | FLIP 指示条 + 淡出淡入 + 光带 |
| `lite`（`.perf` / CDE / 智慧屏） | `.perf` 或自降级 | 全屏纯色层淡入 + 220×1080 斜向扫描带平移，500–700ms，无光晕 | FLIP 指示条 + 纯透明度过渡，300ms，无阴影/光带动画 |
| `off` | `prefers-reduced-motion` | 200ms 纯交叉淡化 | 120ms 透明度 |

CDE/智慧屏验收时以 `lite` 档为准；`full` 档只做"不劣化"检查。

## 方案（已选定）

主题转场选 **B：斜向扫描带 + 交叉淡化**（硬件合成端升级为真实对角卷轴擦除，`.perf` 端退化为扫描带 + 淡化）。标签动效选 **FLIP 指示条 + 内容交叉淡化**。否决的方案：

- **A 对角 clip-path 擦除**：形态最直接，但逐帧改 `clip-path` 是 CPU 光栅化，1920×1080 在 xpra 上会掉帧；且无法做边缘质感。
- **C 双层快照真揭示**：最"真"，但需要静态快照层（DOM 克隆太重，canvas 截图受跨域视频层限制），复杂度最高。
- **标签只做颜色过渡**：成本最低，但"柔和自然"的观感不足。
- **标签内容整页横滑**：接近切页而非切标签，三类标签里节目单会显得过重。

## 详细设计

### 1. 材质令牌（深浅两套）

新增令牌组，现有 `--panel/--card/--line/--tx*` 保留名字并指向令牌，避免全量重命名：

| 令牌 | 深色 | 浅色 |
|---|---|---|
| `--glass-1-fill`（结构层：频道/节目单/设置侧栏） | `linear-gradient(160deg,rgba(30,34,46,.72),rgba(12,15,24,.86))` | `linear-gradient(180deg,rgba(245,248,254,.88),rgba(233,239,249,.78))` |
| `--glass-1-stroke` | `rgba(255,255,255,.14)` | `rgba(255,255,255,.60)` |
| `--glass-1-hi` | `rgba(255,255,255,.22)` | `rgba(255,255,255,.85)` |
| `--glass-1-shadow` | `0 18px 48px rgba(0,0,0,.45)` | `0 18px 48px rgba(24,40,70,.24)` |
| `--glass-2-fill`（交互层：卡片/标签/行/按钮） | `linear-gradient(180deg,rgba(255,255,255,.14),rgba(255,255,255,.07))` | `linear-gradient(180deg,rgba(255,255,255,.82),rgba(255,255,255,.60))` |
| `--glass-2-stroke` | `rgba(255,255,255,.18)` | `rgba(255,255,255,.74)` |
| `--glass-2-hi` | `rgba(255,255,255,.26)` | `rgba(255,255,255,.92)` |
| `--glass-3-fill`（胶囊/徽标） | `rgba(0,0,0,.35)` | `rgba(255,255,255,.70)` |
| `--tx / --tx2 / --tx3` | `#eef1f8 / #a5b1ca / #8499c0` | `#1a2233 / #3a4763 / #5a6b8c` |
| `--tx-weak` | `#6b7c9e` | `#8a94ab` |
| `--acc / --acc2` | `#4d7cfe / #6aa8ff` | `#4d7cfe / #6aa8ff` |

- 所有 `rgba(255,255,255,…)` 文字色改走 `--tx*`；深色下不再有"浅色专用覆盖"的漏网。
- 玻璃四件套（底色渐变 + 顶边 1px 高光 + 折射描边 + 弥散投影）用统一 class/mixin 表达；`::after` 放斜向光带（`linear-gradient(115deg, transparent 30%, rgba(255,255,255,.10) 45%, transparent 60%)`），hover/focus 时 `translateX(2px)` + 透明度变化，纯 `transform`，不触发重绘。
- `.perf` 下：blur 置零、底色提高不透明度到 ≥ .82（深）/ .9（浅），保留描边、高光、投影、光带。
- `@media (prefers-reduced-transparency: reduce)`：同 `.perf` 的实底处理。

文字对比度目标：正文 ≥ 7:1，次要 ≥ 4.5:1，弱化 ≥ 3:1；所有主题专属覆盖逐页核对后删除（第一轮先换文字/表面，第二轮收敛装饰层；顺序由实现者定，但最终不允许残留硬编码白色文字）。

### 2. 标签切换（三类共用）

新增 `tabSwitch` 模块，签名 `tabSwitch(container, opts)`，`opts` 含 `tabSelector`、`onChange`、`rebuild`。

- **指示条**：在 tabs 容器内注入一个绝对定位胶囊 `#lv-tab-ind`，位置/宽度取目标 tab 的 `offsetLeft/offsetWidth`（用 offset 系而非 `getBoundingClientRect`，避免 root 缩放误差）。移动 `transform:translateX()`，260ms，`cubic-bezier(.22,.9,.3,1)`；连续切换时从当前实际位置续接，不跳回。
- **内容过渡**：旧内容 110ms 淡出 + 下移 6px → 执行 `rebuild` → 新内容 180ms 淡入 + 归位。切换前记录 `scrollTop`，切换后恢复；重建只更新 `.on` 与列表内容，tab 节点不再重建（现有 `renderLeftPanel/renderRightPanel` 每帧重建 tabs，需改为建一次、后续只改状态）。
- **快速连点**：用递增 token 丢弃过期回调；动画进行中允许再次切换，从当前状态续接。
- **设置 3 项**：pane 是静态 DOM，只切 `.on`，走同一套指示条 + 淡出淡入，不重建。
- **降级**：`prefers-reduced-motion` → 仅 120ms 透明度，无位移；`.perf` → 300ms，指示条只动 transform、不参与阴影/光带过渡，过渡期间 root 挂 `lptv-tab-anim` 临时关 blur。
- **性能**：tab 节点不重建，只切 `.on`；列表重建按最小节点更新；动画期间不读布局；连续切换从当前 transform 续接。

### 2b. 首页视图转场

首页↔播放/面板/切台的 `setView` 调用处包一层 `viewFade(from, to)`：旧视图 120ms 淡出 + 轻微缩放（0.985），切状态后 240ms 淡入归位；只用 `opacity/transform`，`.perf` 下 160ms、`reduced-motion` 下直接切换。与标签动效区分：标签是横向指示条，视图是整层淡入淡出。

### 3. 遥控导航（新增焦点上下文）

新增 `focusCtx` 模块与按键路由表，优先级：设置打开 > 面板打开 > 播放态 > 首页。

- 设置/面板打开时：←→ 切标签（走 `tabSwitch`），↑↓ 在列表内移动焦点，OK/Enter 激活焦点项，Esc/Backspace 关闭。此上下文内 ←→ 不再调音量。
- 焦点样式：`.focus` 环（`box-shadow:0 0 0 2px var(--acc2)` + 光带），自动 `scrollIntoView({block:"nearest"})`。
- 首页：←→↑↓ 在频道卡片间做空间导航（按几何中心找最近项），Enter 播放；保留 ↑↓ 换台的旧行为仅在播放态。
- 空间导航实现：收集可见可聚焦节点（`offsetParent` 非空且不在隐藏视图内），按方向键取方向向量最近的节点；不做 DOM 顺序假设，兼容卡片两列/列表单列布局。

### 4. 主题切换过渡（右上 → 左下卷轴）

新增 `themeTransition(toLight)`，与 `applyTheme` 解耦，按性能档位分两条路径：

1. 防重入；若正在过渡，直接跳到终态。过渡期间 root 挂 `lptv-theme-anim`（临时关 blur、关光带位移）。
2. `full` 档（仅硬件合成）：创建实色层（目标主题底色，≤2600×2600），旋转 45°，从右上外侧 `translate` 到完全覆盖；边缘跟随一条 220px 卷曲带（暗侧阴影 + 亮侧高光 + 轻微色散渐变）。无 clip-path、无 blur。
3. `lite` 档（CDE / 智慧屏，主路径）：1 个全屏纯色层 opacity 0→1（420ms，延迟 180ms）+ 1 条 220×1080 斜向扫描带 `translateX` 平移（500–700ms），无光晕、无旋转大层；若自降级已生效则退为 3 段阶梯淡化（无扫描带）。
4. 覆盖率达 55–65% 时调用 `applyThemeCore`：切 `data-theme`、换图标、`saveCfg`，**不调用 `renderHome`**（颜色全走令牌，重建会打断过渡并丢滚动）。属性切换在覆盖层之下完成，避免闪白。
5. 500–900ms 内移除过渡层与临时类；结束后恢复 `pointer-events` 与 blur。
6. 变体：默认"卷轴"（卷曲阴影边）；"撕开"作为备选（锯齿边，用重复渐变近似），通过常量切换，不新增设置项。
7. 降级：`prefers-reduced-motion` → 200ms 纯交叉淡化。

`toggleTheme` 改为调用 `themeTransition`；`applyThemeCore` 保留现有持久化语义。过渡期间的 rAF 采样负责写入 `cfg.motionLite`。

### 5. 代码触点

- `web/inject.js` CSS 令牌块（现 `~826` 起）与浅色块（现 `~1384–1775`）。
- `applyTheme/toggleTheme`（现 `~3140–3155`）拆成 `themeTransition` + `applyThemeCore`。
- `renderLeftPanel`（`~3322`）、`renderRightPanel`（`~3418`）tabs 建一次 + `tabSwitch`。
- `_showPane`（`~1857`）接入同一套切换动效。
- 按键处理（`~2960–3032`）加路由层；`isTv()` 分支保留。
- 主题按钮绑定（`~3251`）改调 `themeTransition`。

## 留给实现者的决定

- 令牌收敛分两批还是一次性完成（按可回归验证的时间定）。
- 指示条是否带轻微宽度弹性（当前设计为等宽标签，默认不做宽度动画）。
- 卷轴边带的色散强度、旋转层的实际尺寸（需在 1080p 画布上实测边缘是否露出）。
- 空间导航是否需要"记忆上次焦点"（建议需要，但实现方式自定）。

## 验证

1. 主题切换：深→浅、浅→深各 5 次，含过渡中途再次点击；无闪白/黑屏/残影，首页不重建、滚动位置不丢，重启后主题保持。
2. **主验收在 CDE 与智慧屏（xpra 软件合成）**：用内置帧采样（`window.__lptvPerf` 记录过渡期帧间隔）确认单帧 ≤ 50ms、平均 ≥ 24fps、无连续全屏模糊重绘；若触发自降级，确认 `cfg.motionLite` 持久化且后续动效走 lite 档。Electron/AppImage/exe 只做"不劣化"与 full 档形态检查。
3. 标签：频道分组、节目单 5 天、设置 3 项各连续快切 10 次，指示条不错位、内容不叠层、滚动位置保持；节目单切天不重复请求已缓存日期。
4. 遥控：设置/面板内 ←→ 不调音量；↑↓ 焦点移动可见且可激活；退出后播放态 ←→ 恢复调音量、↑↓ 换台。
5. 可读性：两主题逐页（首页/播放/频道/节目单/设置/切台）扫一遍文字，无白字、无低于目标的弱化文字；浅色下玻璃层可分辨。
6. 降级：`prefers-reduced-motion` 与 `.perf` 下动效收敛且无卡顿；动画结束后 `will-change`、临时类、过渡层全部清理（检查 DOM 无残留节点）；`node --check web/inject.js` 通过。
